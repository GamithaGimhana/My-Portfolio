Desktop / Project overview

Serenity.

Organizing the administrative side of care.

A desktop administration application for patients, therapists, therapy sessions and payment records.

Project typeAcademic project
Contribution / scopeAcademic project
Core technologiesJava · JavaFX · Hibernate
01 / The idea

What is it?

A care center needs to connect people, appointments, programs, and payment records. Serenity is a desktop coursework application focused on organizing these administrative workflows in one system.

02 / The experience

What it does.

01

Patient registration

Manage patient information through a dedicated administration workflow.

02

Therapists and programs

Keep therapist and program records within the application.

03

Therapy sessions

Organize session-related records alongside the people and programs involved.

04

Payments and dashboards

Maintain payment records and present role-specific dashboard interfaces.

03 / Under the surface

How it’s built.

JavaFX provides the desktop interface and controllers. Hibernate connects domain entities to MySQL persistence, with JasperReports included for reporting functionality.

  1. JavaFX interface
  2. Hibernate
  3. MySQL

04 / The work

Project scope.

The public JavaFX application includes controllers for patient registration, therapist and program management, therapy sessions, payments, users, and role-specific dashboards. Its Maven configuration includes Hibernate, MySQL, and JasperReports.

Technical focus

Desktop application structure, object-relational mapping, and administrative workflows. This is an academic administration project, not a clinical decision system.
