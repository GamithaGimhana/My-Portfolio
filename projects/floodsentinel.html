AI & Data / Project overview

FloodSentinel.

Exploring flood scenarios through maps and machine learning.

A Sri Lanka flood-scenario dashboard connecting district maps, live weather data and a machine-learning pipeline.

Project typeAcademic team project
Contribution / scopeGeospatial frontend & ML
Core technologiesReact · TypeScript · Python
01 / The idea

What is it?

Environmental measurements become easier to explore when their location and context are visible. FloodSentinel is an academic investigation into connecting district-level maps, weather inputs, and a machine-learning pipeline in one interface.

Project context

The model is trained on synthetic scenarios. It is not an official warning system or a verified measure of real-world flood probability.

02 / The experience

What it does.

01

District-level exploration

A geospatial interface organizes the system around Sri Lankan districts.

02

Weather inputs

Weather ingestion supplies contextual data for the dashboard and scenario workflow.

03

Scenario modelling

A Python machine-learning pipeline works with synthetic flood scenarios.

04

Connected dashboard

A React interface connects map exploration with backend model outputs.

03 / Under the surface

How it’s built.

React and TypeScript support the dashboard, with Leaflet providing map interactions. A FastAPI backend connects the interface to Python modelling components built with scikit-learn.

  1. React + Leaflet
  2. FastAPI
  3. scikit-learn pipeline
