Web Apps / Project overview

Aurora LMS.

A learning space that brings the essentials together.

A learning platform bringing quizzes, live quiz rooms, notes and flashcards into one role-based experience.

Project typePublic project
Contribution / scopeFull-stack development
Core technologiesReact · TypeScript · Node.js
01 / The idea

What is it?

Quizzes, study notes, flashcards, and class participation are closely related parts of learning. Aurora brings them into a shared application, with different workflows for students, lecturers, and administrators.

02 / The experience

What it does.

01

Role-based workspaces

Separate experiences organize the tasks of students, lecturers, and administrators.

02

Quizzes and room participation

Lecturers can create quizzes, while students join quiz rooms and complete attempts.

03

Study resources

Notes and flashcard decks support learning beyond a single quiz session.

04

Performance views

Dashboard views bring learning activity and results into the application.

03 / Under the surface

How it’s built.

A React and TypeScript frontend manages the interface and client state. It connects to a Node.js and Express REST API, with MongoDB providing document storage. Frontend and backend are maintained in separate public repositories.

  1. React interface
  2. Express REST API
  3. MongoDB

04 / The work

My contribution.

I built the frontend and backend, connecting React and TypeScript views to Node and Express REST APIs. I designed MongoDB data models, managed application state and data flow, and deployed the frontend on Vercel.

Technical focus

Role-based interfaces, frontend/backend integration, and organizing a complete learning workflow.
