Mobile / Project overview

Aurora Mobile.

A study companion that goes where you go.

A mobile study companion for organizing notes, reviewing flashcards and keeping learning close at hand.

Project typePublic project
Contribution / scopeMobile development
Core technologiesReact Native · Expo · TypeScript
01 / The idea

What is it?

Study materials should be easy to revisit away from a desktop. Aurora Mobile adapts note organization and flashcard review into a focused mobile experience for managing learning resources on the go.

02 / The experience

What it does.

01

Organized notes

Create, retrieve, update, and delete notes from a mobile interface.

02

Flashcard study

Flashcard decks and study sessions provide a dedicated space for review.

03

Account access

Email and password authentication is integrated through Firebase Auth.

04

Personal viewing preferences

Light and dark themes support different reading preferences.

03 / Under the surface

How it’s built.

React Native and Expo provide the application foundation. TypeScript and Redux Toolkit organize application data and state, NativeWind supports interface styling, and Firebase supplies authentication and Cloud Firestore persistence.

  1. React Native + Expo
  2. Redux Toolkit
  3. Firebase
React NativeExpoTypeScriptFirebaseRedux ToolkitNativeWind
04 / The work

My contribution.

I built the React Native interface, implemented application state with Redux Toolkit, and integrated Firebase authentication and Firestore. I used TypeScript and custom hooks to organize the code, and Expo Application Services to manage the mobile build workflow.

Technical focus

Mobile interaction design, state management, authentication, and cloud-backed study resources.
