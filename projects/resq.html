Cloud & Backend / Project overview

RESQ.

A shared command portal for response coordination.

A disaster-response command portal for mapping incidents, coordinating teams and managing digital evidence.

Project typeAcademic project
Contribution / scopeAcademic project
Core technologiesReact · TypeScript · Spring Boot
01 / The idea

What is it?

Incident information, team allocation, and evidence can sit in separate workflows. RESQ explores how a command portal and domain services can bring these responsibilities together in a disaster-response application.

02 / The experience

What it does.

01

Incident mapping

The portal provides an interface for viewing and working with incident information.

02

Response coordination

Response workflows organize team allocation and related operational records.

03

Evidence management

A dedicated domain service supports the management of digital evidence.

04

Cloud infrastructure

Terraform definitions describe infrastructure alongside the application services.

03 / Under the surface

How it’s built.

A React and TypeScript portal connects to Spring-based domain services. The system separates incident, response, and evidence responsibilities, using service discovery and an API gateway. Infrastructure definitions target Google Cloud.

  2. API gateway
  3. Domain services
