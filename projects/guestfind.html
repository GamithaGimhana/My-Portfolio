Web Apps / Project overview

GuestFind.

Helping lost belongings find their way back.

A hotel lost-and-found platform that takes items from initial report through claim approval and delivery.

Project typePublic project
Contribution / scopePersonal project
Core technologiesJava · Spring Boot · Spring Security
01 / The idea

What is it?

A lost item creates a sequence of tasks: reporting it, identifying a match, checking a claim, and arranging its return. GuestFind organizes that sequence for hotel staff and guests in a shared web application.

02 / The experience

What it does.

01

Item reports

Record lost and found belongings so they can be managed through a structured workflow.

02

Matching and claims

Connect possible matches with a claim review and approval process.

03

Delivery management

Track the next step after a claim has been approved.

04

Role-specific access

Different responsibilities are organized for administrators, staff, and guests.

03 / Under the surface

How it’s built.

A Java and Spring Boot backend exposes REST APIs and uses Spring Security for access-related functionality. MySQL stores application data, while a browser frontend presents reporting and management workflows.

  2. Spring Boot REST API
  3. MySQL

04 / The work

Project scope.

This project brings together a Spring Boot REST backend and an HTML, CSS, and JavaScript frontend. Separate administrator, staff, and guest workflows support the different responsibilities in the lost-and-found process.

Technical focus

Modelling a multi-step business process and connecting roles, application state, and persistent records.
