Cloud & Backend / Project overview

Automated Greenhouse.

Connecting the moving parts of greenhouse management.

A distributed greenhouse management system connecting telemetry, automation rules and crop lifecycle tracking.

Project typeAcademic project
Contribution / scopeAcademic project
Core technologiesJava · Spring Cloud · Eureka
01 / The idea

What is it?

Zones, sensor readings, automation decisions, and crop records represent different parts of greenhouse operations. This project explores how to model those responsibilities as cooperating services instead of one tightly coupled application.

02 / The experience

What it does.

01

Zone management

Organize greenhouse zones as a distinct application responsibility.

02

Sensor data

A telemetry service handles sensor-related records and inputs.

03

Automation rules

Automation actions are separated from the collection of telemetry.

04

Crop lifecycle

Crop records are managed by their own domain service.

03 / Under the surface

How it’s built.

Java and Spring Cloud provide the service foundation. Eureka supports discovery, a central configuration server coordinates configuration, and an API gateway provides an entry point to the domain services. MySQL supports persistence.

  1. API gateway
  2. Spring Cloud services
  3. MySQL

04 / The work

Project scope.

The public project implements a distributed management system with four domain services. A registry, central configuration server, and gateway provide the supporting service infrastructure.

Technical focus

Service boundaries, discovery, central configuration, and coordination across a distributed application.
